Method / reproducibility

What was measured

Fixed questions and policy

Model jev-1.13.0 (Jeff) judges the route, supported model, missing model and reported hazard. Code composes those judgments into the next step.

  • Hazard probability ≥ 0.50 → technician review.
  • Non-charging route or selected-route probability < 0.70 → technician review.
  • Missing-model probability ≥ 0.60 or no single supported model → clarification.
  • Selected-model probability < 0.70 → technician review.
  • Meridian M2 has no compatible stock → technician review. A supported Northstar N14 charging request may reach an estimate requiring approval.

One frozen synthetic run

The original record states that labels, the 6/42 split and thresholds were fixed before successful inference, with no tuning on the holdout. Results and measurements are preserved from that run.
